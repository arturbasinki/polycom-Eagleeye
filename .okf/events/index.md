# events

* [Light Correction Applied](/events/light-correction-applied.md) - The event that a tone curve has been accepted and applied to the output.
* [Person Selected](/events/person-selected.md) - The event that the operator has picked a person to follow.
* [Privacy Enabled](/events/privacy-enabled.md) - The event that privacy mode has been activated and the room is hidden.
* [Target Acquired](/events/target-acquired.md) - The event that a target is found again and the director returns to tracking.
* [Target Lost](/events/target-lost.md) - The event that the tracked person has not been measured for too long, triggering the loss ladder.
